# CHANGELOG

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo.
O formato é baseado em [Keep a Changelog](https://keepachangelog.com/pt-BR/1.0.0/), e este projeto adere ao [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [3.0.0] - 2026-06-26

### Sovereign Cloud Edition

#### Added
- Middleware Rust em produção (Render.com) integrando interceptação na camada de aplicação (OSI Layer 7).
- Modelo BYOK Nativizado (Bring Your Own Key) para faturamento descentralizado e otimização de custos de LLM.
- CivitasVote Institucional lançado para pesquisas seguras no mercado LATAM.
- 18 testes de proteção de IP validados com 100% de eficácia contra exfiltração em Red Teaming.
- Dossiê Transparência Soberana disponibilizando 135 testes públicos categorizados.

#### Changed
- Frota APEX consolidada estruturalmente em 5 agentes especializados primários (Wolfdog, Kangal, Pitbull, Sentinel Prime, Certus Guardian), coordenando o restante do Conselho de Estado.
- Latência documentada do Input Guard reduzida para ~5ms, validada empiricamente.
- Atualização do status legal: 14 pedidos de patente em preparação para depósito no INPI.

#### Security
- Defesa em profundidade reforçada: Input Guard (Pré-interceptação) + Output Guard (Análise de Stream) + LAZARUS Vault (Auditoria Imutável).
- Zero vazamentos (0%) atestados nos 18 testes cirúrgicos de engenharia reversa sob NDA.
